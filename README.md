# 閉じた家 / Closed Room

サイコロジカルアドベンチャーゲーム（試用版）

## 遊び方

ブラウザで `index.html` を開くだけで動作します。
インストール不要です。

## GitHub Pages での公開方法

1. このリポジトリを GitHub に push する
2. リポジトリの **Settings → Pages** を開く
3. Branch を `main`、フォルダを `/ (root)` に設定して **Save**
4. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で公開される

## 現在の収録範囲（試用版）

- 道路（開始地点）
- 玄関前 / たぬきの置物
- 玄関ホール
- 1階・台所（祖母）
- 階段・踊り場（鏡）
- 2階廊下（入口まで）

